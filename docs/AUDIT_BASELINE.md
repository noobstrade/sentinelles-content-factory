# Baseline — audit externe reçu

Ce document enregistre les constats rapportés ; ils ne sont pas déclarés corrigés tant qu'un test ne le prouve pas.

## Plaquette
- Document encore à finaliser.
- Offres « à valider ».
- Contacts incomplets.
- Audience non chiffrée.
- Consignes internes visibles.
- Les formules doivent préciser quantités, délais et contreparties.

## Audit / stratégie
La direction est jugée pertinente, mais les notes élevées, le potentiel sponsoring et l'objectif de temps bénévole ne sont pas encore étayés par des mesures documentées.

## Prototype
Défauts confirmés dans l'audit reçu :
- seul le premier rush est utilisé pour les exports ;
- trois clips peuvent être identiques ;
- les générations précédentes d'un même événement peuvent être écrasées.

Fonctions signalées absentes :
- sous-titres ;
- sélection intelligente ;
- reporting partenaires.

## Priorité
Préciser l'offre → fiabiliser le prototype → mesurer un événement pilote réel.
